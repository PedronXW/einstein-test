# F-026 — CI (GitHub Actions) — testes automáticos em push/PR

## O que foi feito
Pipeline de **CI no GitHub Actions** que roda em push/PR:

- **Job `test`**: `uv sync --dev` → `ruff check .` (lint) → `pytest -m "not
  integration"` (unitários + specs, **sem** integração que exige credenciais) →
  upload do relatório JUnit.
- **Job `alembic`**: sobe um postgres pgvector (service container) → `alembic
  upgrade head` → `alembic check` (valida schema sem drift).
- Integração (`-m integration`) fica **fora** do CI padrão (chave/infra
  ausentes).

## Notas
- O `alembic check` exige que o schema do modelo esteja em sync com as
  migrations — falha o CI se houver drift (ex.: model alterado sem migration).
- O `ruff check .` valida estilo/lint básico; ajustes podem ser necessários se
  o código não seguir totalmente o padrão do ruff.
